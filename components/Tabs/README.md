# Tabs

Uppercase tabs over a hairline, with a red `stroke-4` bar under the active tab.

- The consumer provides `items` (`id`, `label`, `content`) and a `label` naming the tab list. Use `value` with `onChange` to control it, or `defaultValue`.
- Arrow keys, Home and End move between tabs.
- Use two to five tabs of peer content. Do not use tabs for steps in a sequence.
