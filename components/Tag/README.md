# Tag

A small uppercase label for status and category, carrying its primary's shape so meaning never rests on colour alone.

- The consumer provides one to two words as children and a `tone`.
- `red` (square) for danger and overdue, `yellow` (triangle) for warnings and due soon, `blue` (circle) for information and done. `neutral` is an outline in `line` for plain categories.
- Tags are not buttons: make the surrounding row the click target instead.
